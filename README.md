# 🌻 Ashi vs Zombie: Defense of the Dorm (อชิ ปะทะ ซอมบี้) 🧟

เกมแนว **Plants vs Zombies** สไตล์ล้อเลียนสุดฮาและเต็มไปด้วยฟีเจอร์จัดเต็ม โดยนำภาพมีมและรูปถ่ายสุดพิเศษของ **"อชิ" (Ashi)** มาแปลงเป็นกองทัพพืชผู้พิทักษ์และฝูงซอมบี้ผู้หิวกระหายสมอง!

---

## 🎮 วิธีเปิดเล่นเกม (How to Play)

1. **ผ่านคำสั่ง npm (แนะนำ):**
   ```bash
   npm run dev
   ```
   ระบบจะเริ่ม Dev Server (Vite) และเปิดเบราว์เซอร์ไปที่ `http://localhost:5173` ให้โดยอัตโนมัติทันที!

2. **ผ่านไฟล์ Batch:**
   ดับเบิ้ลคลิกไฟล์ `play_game.bat` ในโฟลเดอร์นี้

3. **เปิดเล่นโดยตรง:**
   เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Firefox)

---

## 🌟 จุดเด่นและระบบของเกม (Key Features)

- **มีหลายด่าน (Multi-Stage Campaign)**: รวมกว่า 8+ ด่าน ครบทุกบรรยากาศคลาสสิกของ PvZ:
  - ☀️ **World 1: Campus Day (สนามหญ้ากลางวัน)**: แดดส่องสว่าง มีดวงอาทิตย์ตกลงมา เรียนรู้พื้นฐานและปลดล็อกพืชตัวแรกๆ
  - 🌙 **World 2: Dormitory Night (หอพักยามค่ำคืน)**: ไม่มีดวงอาทิตย์ตกจากฟ้า! ต้องพึ่งพา Sun-Ashi อย่างเดียว และมีป้ายหลุมศพ (Graveyard) ที่ซอมบี้จะโผล่ออกมาตอนคลื่นใหญ่
  - 🏊 **World 3: Pool Party (สระว่ายน้ำกลางแจ้ง)**: เลน 2 และ 3 เป็นน้ำ! ต้องใช้ใบบัว (Lilypad) รองก่อนปลูกพืชชนิดอื่น มีซอมบี้ดำน้ำและแทงก์โซฟา
  - 🏛️ **World 4: Campus Rooftop (ดาดฟ้ามหาวิทยาลัย)**: หลังคาลาดเอียง มีกระสุนวิถีโค้งและพลังทำลายล้างสูงสุด
  - 👑 **Stage 4-2: FINAL BOSS (ศึกตัดสิน มหาจักรพรรดิอชิ)**: บอสใหญ่ขนาดยักษ์ เลือด 6,500 หน่วย มีหลอดเลือดบอสบนจอ พร้อมท่ากระทืบเลน สั่นสะเทือนหน้าจอ และเสกฝูงซอมบี้!
- **ระบบเสียงสังเคราะห์ Web Audio API**:
  - เสียงยิงกระสุน, เสียงกระทบเนื้อซอมบี้, โดนถังเหล็ก/โล่กล่องพิซซ่า
  - เสียงเก็บดวงอาทิตย์เป็นคอร์ดเปียโนไพเราะ
  - เสียงระเบิดตูมตาม, เสียงเผาทำลายล้างของนกเหลือง
  - เสียงซอมบี้คำรามสุดกวน
  - ดนตรีประกอบ BGM สังเคราะห์อัตโนมัติแบบ Chiptune/Synth ตามธีมของแต่ละด่าน (Day, Night, Boss)
- **ระบบความเร็วเกม (Speed Toggle)**: ปรับความเร็ว 1x หรือ 2x ได้ตลอดเวลา
- **ระบบสารานุกรม (Ashi Almanac)**: กดเปิดดูสเตตัส, ค่าพลัง, ประวัติตัวละคร และวิธีแก้ทางของพืชและซอมบี้ทุกตัวในเกม
- **เครื่องตัดหญ้าอชิเหินฟ้า (Flying Ashi Lawnmower)**: ไม้ตายสุดท้ายประจำเลน เมื่อซอมบี้หลุดเข้ามา อชิจะบินพุ่งทะลวงกวาดเรียบทั้งแถว!

## 🧟 รายชื่อซอมบี้ (Zombie Types - 7 ชนิด)

1. **Ashi Zombie (ซอมบี้อชิชุดขาด)**: ซอมบี้พื้นฐาน HP 200 เดินมุ่งหน้าเข้าหอพัก
2. **Conehead Ashi (ซอมบี้กรวยส้ม)**: สวมกรวยจราจร เพิ่มเกราะป้องกัน +350 HP
3. **Buckethead Ashi (ซอมบี้ถังเหล็ก)**: สวมถังเหล็กสุดแกร่ง เพิ่มเกราะ +800 HP
4. **Pizza Box Ashi (ซอมบี้โล่กล่องพิซซ่า)**: ถือกล่องพิซซ่าเป็นโล่ ป้องกันกระสุนตรงทุกชนิด! (ต้องใช้ใยสไปเดอร์วิถีโค้งหรือระเบิดโจมตี)
5. **GigaChad Ashi (ซอมบี้กิกะแชด นักกระโดดค้ำ)**: วิ่งเร็วกว่าปกติ 2 เท่า และใช้ไม้ค้ำกระโดดข้ามพืชตัวแรกได้ทันที!
6. **Couch Tank Ashi (ซอมบี้โซฟาขี้เกียจ)**: ซอมบี้แทงก์ยักษ์ เลือด 1,600 HP บดขยี้พืชอย่างช้าๆ
7. **EMPEROR ASHI BOSS (มหาจักรพรรดิอชิบอสใหญ่)**: บอสใหญ่ประจำด่าน 4-2 เลือด 6,500 HP มีสกิลเสกฝูงซอมบี้และกระทืบทำลายเลน!
